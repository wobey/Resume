## Project Goals
- ASP.NET Core Razor Pages
- Single-page portfolio
- Modern, clean, professional
- Optimize for recruiters and hiring managers
- Responsive design
- Semantic HTML
- Accessible

## Coding Standards
- When asked to commit, first check whether PROJECT_STATUS.md is stale (finished work still under "In Progress," outdated "Last Updated" date, outdated "Next Up") and fold any needed update into the same commit.
- After making a change to a page, always show it: run/restart the app and open or refresh Chrome to the changed page, without waiting to be asked.
- Explain changes before making them.
- Prefer maintainable code over clever code.
- Use Flexbox unless Grid is clearly better.
- Keep CSS modular.
- Don't introduce JavaScript unless necessary.
